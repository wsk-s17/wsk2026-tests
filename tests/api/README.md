# API тесты (Bruno)

Проверяют REST API демо-проекта [server-side](../../server-side): вход по
токену, заметки, ошибки валидации.

Тесты сравнивают коды ответов и JSON целиком. Лишний пробел или другая буква в
`message` - тест упадёт.

## Запуск из терминала

Сначала запустите server-side (http://localhost:8000).

```bash
npm install
npm test
```

Одна папка:

```bash
npx bru run "02 Notes" --env Local
```

## Запуск в приложении Bruno

1. Open Collection -> выбрать эту папку.
2. Справа вверху выбрать окружение `Local`.
3. Правой кнопкой по коллекции или папке → Run.

Запрос можно открыть и отправить вручную. Результат проверок — на вкладке Tests.

## Окружение

`environments/Local.bru`:

| Переменная | Значение                    |
| ---------- | --------------------------- |
| `baseUrl`  | `http://localhost:8000/api` |
| `email`    | `demo@test.wsk`             |
| `password` | `demopass`                  |

Если API на другом адресе - поменяйте `baseUrl`.

## Как устроены тесты

- Папки и запросы выполняются по порядку (`01`, `02`, ...).
- Каждая папка начинается с `Login`: он сохраняет токен в переменную `token`,
  остальные запросы отправляют его в `Authorization: Bearer`.
- Значения из ответа передаются дальше через `bru.setVar`, например id созданной
  заметки.
- Проверки - в блоке `tests` в конце каждого `.bru` файла.
